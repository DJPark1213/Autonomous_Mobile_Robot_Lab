ROS Computation Graph
Ø Nodes
Ø Are executables that use ROS to communicate with other nodes.
Ø A ROS node is written with the use of a ROS client library, such as roscpp or rospy.
Ø Messages
Ø A ROS message is a data structure, comprising typed fields. Nodes communicate
with each other by passing messages. (Structures defined in .msg files)
Ø Topics
Ø Each topic is a message bus that carries a certain type of message.
Ø Multiple nodes can subscribe and publish to a single topic.
Ø One node can subscribe and publish to many topics.
•Autonomous Mobile Robots
